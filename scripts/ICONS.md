# Icon sources

`icons.json` holds the shape data for the tech stack tiles, taken from:

- [Simple Icons](https://simpleicons.org) v16.32.0 (CC0 1.0): brand logos
- [Devicon](https://devicon.dev) v2.16.0 (MIT): Java, Oracle, VS Code
- [Lucide](https://lucide.dev) v1.48.0 (ISC): SQL, Web Animation, Schema Design, Query Optimization, UI/UX Design, Graphic Design

Brand logos remain trademarks of their respective owners.
